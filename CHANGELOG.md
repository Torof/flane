# Versions

Each version of the app has a number and a name saying what it brings (D-029, `docs/METHOD.md`). Most recent first. The merge commit of each version is tagged (`v0.0.2`).

## 0.0.2 — Updates without reinstalling · 2026-10-20

The test version on the phone receives each new slice in seconds, without installing a new APK (EAS Update, `app.flane.dev` only, D-023). « About » shows the app version and the native version.
